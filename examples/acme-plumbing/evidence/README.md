# Synthetic evidence

This example is synthetic. It does not include real screenshots, Lighthouse JSON, or client evidence.

A real run stores evidence here:

- `m-01-home.png`, `d-01-home.png`, and other viewport screenshots
- `lighthouse-mobile-1..3.json`
- any scheduler screenshot used as evidence

The verifier's `--synthetic` flag waives screenshot and Lighthouse file checks for this example only. A delivered client run must include them.
